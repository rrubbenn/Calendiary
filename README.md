# Calendiary

This is a to-do list application where you can add groups and assign tasks to those groups.

The entire application serves as a testing ground, which means there might be several aspects that aren't optimal or fully coherent, but they are intentionally included for the purpose of learning and experimenting. My goal is to explore different features and improve my understanding of Angular, so some things might not be the best implementation yet.

One of the features I plan to add is a calendar tab, which should look something like this:
![image](https://github.com/user-attachments/assets/885da775-5d8a-4b76-878e-4611db5a0257)
but I want to explore other technologies before implementing it as I have a basic understanding of Angular.

Angular features and technologies used in this project:

RouterLink for navigation between views.
Signals for reactive communication between components.
Services for data management and application logic.
Angular Material for design and UI components.
Angular Material Menu for creating interactive menus.
Angular Modals for displaying pop-up windows.

I welcome any feedback or suggestions as I continue working on this project.
