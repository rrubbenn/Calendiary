# Calendiary

**Calendiary** is a to-do list application that allows you to create groups and assign tasks to those groups.

The entire application serves as a **testing ground** for learning and experimentation.  
As such, some features may not be fully optimized or coherent, but they are intentionally included to help me explore and learn different aspects of Angular.

## 🛠️ Installation

To install and run this project locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/rrubbenn/calendiary.git
    ```
2. Navigate to the project folder:
    ```bash
    cd calendiary
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Run the application:
    ```bash
    ng serve
    ```
5. Open your browser and go to `http://localhost:4200` to view the app.
